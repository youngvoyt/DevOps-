# Data Dictionary – course_project_test.csv

## Общая информация

- **Источник данных**: локальный файл `course_project_test.csv` (корень репозитория)
- **Тематика**: кредитование, предсказание дефолта заемщиков.
- **Единица наблюдения**: один заемщик или одна кредитная заявка.

## Примерная структура полей

| Имя поля          | Тип        | Описание                                                |
|-------------------|-----------|---------------------------------------------------------|
| client_id         | int       | Уникальный идентификатор клиента                       |
| application_id    | int       | Уникальный идентификатор кредитной заявки              |
| target_default    | int (0/1) | Целевой признак: 1 — дефолт, 0 — нет дефолта           |
| gender            | string    | Пол клиента                                            |
| age_years         | int       | Возраст клиента в годах                                |
| income_total      | float     | Доход клиента                                          |
| credit_amount     | float     | Сумма кредита                                          |
| credit_term_months| int       | Срок кредита в месяцах                                 |
